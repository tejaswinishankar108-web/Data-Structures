# HASH TABLE
## Introduction
#### A hash table is a data structure that stores information in key-value pairs.
#### Converting key into the index
It uses a mathematical formula called a hash function to turn a key into an array index, i.e., it converts into a number(ASCII Values of the key) using hash() function 
Ex: if key = 'a', 'b', 'c' => hash(key) = ASCII(a), ASCII(b), ASCII(c) = 97 + 98 + 99 
This index decides where the matching value lives. 
It lets programs find, add, and remove data very fast
#### Indexing
index = hash(key) % table_size
if table_size = 10
for a : 97 % 10 = 7
for b : 98 % 10 = 8
for c : 99 % 10 = 9
